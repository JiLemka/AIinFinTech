# Мини-проект по оценке кредитных рисков

Модель машинного обучения, которая по данным о заемщике и кредитной заявке прогнозирует вероятность дефолта (PD).
Решение — в ноутбуке [credit_risk.ipynb](credit_risk.ipynb) (выполнен, все выводы и графики сохранены).

**Датасет:** German Credit Data (Statlog), UCI / OpenML `credit-g` — 1000 заявок, 20 признаков, 30 % дефолтов.
Файл: `data/german_credit.csv`. Повторная загрузка:

```python
from sklearn.datasets import fetch_openml
fetch_openml('credit-g', version=1, as_frame=True).frame.to_csv('data/german_credit.csv', index=False)
```

**Результат:** ансамбль (логистическая регрессия + случайный лес + градиентный бустинг), ROC-AUC 0,813, Gini 0,625 на отложенной выборке.
Трехзонное правило (PD < 0,2 — одобрить, 0,2–0,5 — проверка, ≥ 0,5 — отклонить) дает +296 DM на заявку против −132 DM без модели (ставка 15 %, LGD 60 %).
